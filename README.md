# 拆集工作台 · Mac 单体应用

目标：一个 `.app` / `.dmg`，运行时不需要打开终端、输入连接码或单独安装 Python/FFmpeg。视频仅从用户选择的本地/NAS 挂载目录读取，并直接输出到用户选择的目录。

`main.js` 在应用启动时自动运行打包在 `Contents/Resources` 的处理引擎，内部使用本机回环端口；网页界面不再向用户暴露该机制。PyInstaller 将 Python 与 Pillow 一同打包，FFmpeg/ffprobe 二进制文件作为应用资源随包分发。请遵守二进制文件的许可与署名要求。

## 构建与分发

GitHub Actions 的 `Build macOS app` 工作流在 macOS ARM64 环境生成 DMG。该工作流当前不进行 Apple Developer ID 签名或公证；给他人稳定分发前，应配置签名、公证并在真实 Apple Silicon Mac 上验证安装、文件权限、NAS 读写和 30GB 以上项目。Linux 环境不能替代 macOS 的运行验收。

## 当前能力

- 本地文件夹 / 已挂载 NAS 目录导入后立即按文件名集数数字排序（1、2、10）；可填写顺序号、上移下移、排除文件或恢复数字排序。源文件缺号只提示，不阻断拆集。
- 以原集边界和强剧情切点为先，目标集数只作参考；新集号连续，列表标明原集与片段序号；可手工修正切点。
- 纯净海报编号样式、实际样片首帧核对与逐集导出；H.264 MP4 1080×1920、25 FPS、AAC 双声道。
- 旧定帧与开头海报帧自动识别，也可按源视频帧数补充片头裁切、逐原集调整；新片尾提供起始/中间/结束关键帧缩放和短片预览。
- 新片尾可选定帧、闪光、暖色炫光或自定义 MP4/MOV/WebM 视频层；非透明效果默认提取亮部并限制混合强度，另有滤色、变亮和亮度叠加模式，可选本机音效。
- 本地任务状态保存、设置变更后样片失效，以及已完成文件指纹跳过。导出目录只包含按实际新集号命名的 MP4（如 20.mp4）；续导记录保存在应用缓存中。若数字文件名与目录中已有文件冲突，会提示更换目录，避免覆盖现有素材。

情绪峰值和隐藏信息目前只是音频/镜头候选，仍需人工复核；已烘焙进唯一源片的效果无法无损还原。非透明效果的亮部提取适合暗底光效，包含完整场景的素材可能仍需在预览中调整阈值或先制作效果层。用户提供的参考视频和音频没有放入公开仓库。没有大于 30GB 的真实素材验收前，不宣称生产环境容量已验证。
